## Priority Issues

### [P1] Charts are invisible to keyboard and screen readers
VBars/AreaTrend/Heatmap expose values only via onMouseMove/onMouseEnter — no tabIndex, role, or aria alternative. The whole Análises page is blank to Sam. Fix: wrap each in figure role=img aria-label with the key numbers; add a visually-hidden data table + visible toggle; make points focusable with arrow traversal. Command: /impeccable audit.

### [P1] The CRUD monoculture and missing table mechanics
14 screens are the same CrudPage factory; reference data gets the same shell as living operational surfaces; no sort/multi-select/bulk/pagination anywhere; the detail drawer re-prints columns. Fix: split lean config lists from operational entities (sortable columns, bulk enable/disable/delete, sticky filter, pagination/virtualization, purpose-built detail). Command: /impeccable distill then /impeccable shape.

### [P1] The dashboard is the landing for every persona and has no primary action
5 KPIs + 7 stacked cards; the cashier crosses it to reach the PDV. Fix: lead each persona with its one queue (caixa -> PDV/pickups, farmacêutico -> rx queue, gerente -> store exceptions), cap KPIs at 3, demote the rest; consider the PDV as the caixa landing. Command: /impeccable distill.

### [P2] The store switcher is functionally inert
storeIdx changes only the rail label; PainelPage hardcodes STORES[0]; no operational screen is store-scoped. Credibility hit for a 3-store chain. Fix: thread store scope through page data, surface it in the breadcrumb, default each persona to their store with "ver a rede" as the zoom-out. Command: /impeccable shape (functional).

### [P2] Small but real accessibility and state gaps
.switch track is 20px tall (below WCAG 2.5.8 AA 24px); chat send button has no accessible name; Cotações accordion header + rail store trigger + its menu options are keyboard-dead <div onClick>; in-session mutations don't update rail badges/bell (module-constant counts); the 6s toast auto-dismiss loses the keyboard undo affordance. Fix: bump switch >=24px, aria-label the send button, convert the 3 <div onClick> to buttons, lift ORDERS/PRESCRIPTIONS/CHATS/stock to shared state, pause the toast on hover/focus. Command: /impeccable harden + /impeccable audit.
